# Citofonía Mobile

App nativa con Expo Router, TypeScript, Context API, Axios, rutas por rol.

## Funcionalidades
- Login / Registro de residente
- Redirección por rol: ADMIN / CONCIERGE / USER
- Dashboards responsive (móvil/tablet)
- Listo para react-native-webrtc

## Configurar API
`src/config/api.ts` - cambiar IP según emulador/dispositivo

## Ejecutar
```bash
cd mobile
npm install
npx expo start
```
