# Citofonía Móvil — Directivas del Proyecto

## Ámbito de Trabajo (¡ESTRICTO!)
- **Ruta Única de Frontend:** Trabajar EXCLUSIVAMENTE dentro de la carpeta `mobile/` (o la carpeta de Expo).
- **Prohibición Total:** NO modificar, leer ni refactorizar nada dentro de la carpeta `front/` (es solo para pruebas locales de SparkleCow).

## Estilo de Respuesta (Ahorro Máximo de Tokens)
- Respuestas directas, concisas y técnicas.
- Cero saludos, cero explicaciones teóricas y cero resúmenes al final.
- Entregar solo el código modificado o los diffs concretos.

## Directivas Mobile (Expo + NativeWind / React Native)
- **Target:** Responsivo para smartphones y tablets (Android/iOS).
- **Filosofía UX:** Sin sobre-ingeniería. Interfaces limpias, funcionales y de alto contraste.
- **Caso de Uso:** Pantallas orientadas a la citofonía residencial (llamada rápida, alertas de acceso, lista de residentes/apartamentos, apertura de puerta).
- **Diseño Responsivo:** Usar unidades flexibles (`flex`, porcentajes, o clases responsivas) para que escala perfectamente en pantallas grandes (tablets de portería) y pantallas de smartphones.
